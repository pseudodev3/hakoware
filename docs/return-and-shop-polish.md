# Home, conversations, Circle and shop polish

Home now presents one featured Duo with its actual latest message and reply/recap action. Three other friends use the same compact rows as Circle. The featured friend and its separate message panel no longer repeat below the hero; their obsolete variant and styles are removed. Exact latest-message deduplication still leaves older replies and updates from other friends reachable. A quiet one-Duo Home does not create an empty conversation section. Sidebar guidance skips messages/recaps already handled by the lead, while first check-ins, other friends' updates, moments and real check-in windows remain available.

Routine check-ins, reactions, pokes, identity changes and recovery updates use compact inline text, XP and timestamps. Their event IDs, deep-link focus, actions and pagination remain intact. Message bubbles, voice content, milestone replays and shared moments retain their existing behavior and prominence.

Circle searches the actual partner's name/handle and the Duo name, ignoring case and Latin accents. All, Unread and Check-in due filters combine with that search. Due uses the existing `canCheckin` gate, including season-start baselines, participant perspective, the 20-hour window and completed-season exclusions. Bankrupt-partner priority remains first, followed by unread activity and recency. Missing social data is labelled loading/unavailable rather than presented as an empty unread inbox. Counts refresh while the page is visible; filters reset on account changes. Invitations remain outside the active-roster filters.

The shop replaces its plain card dropdown with four accessible thumbnail buttons. Prices, currency and checkout now precede the profile/inclusions section. New NOWPayments self/gift actions explicitly say Pay with crypto / Gift with crypto; legacy Stripe retains its own copy and recovery. Bundle savings compare fully configured prices in matching currency/minor units, without fixed percentages or assumed launch amounts. Missing/mixed prices, unsafe totals, incomplete edition coverage and partial ownership suppress savings. Gift checkout does not assert a saving on a recipient's remaining editions when that ownership detail is unknown. Payment amounts, eligibility, retry keys and delivery still come from the existing checkout system.

Home's Sparks preview distinguishes loading, a confirmed empty feed and failures. A 503/507 response gets a paused state; other failures get a retryable loading error. Account changes cannot display another account's previous preview. The full feed disables share promotions during unavailability, keeps cached posts readable and provides Check again / Open your circle. Explicit refreshes are not superseded by background polling; successful recovery updates an initially empty feed. A failed publish keeps its draft/retry intent and uses useful paused copy. This changes presentation and recovery behavior; it does not fix Railway storage or remove index guarantees.
